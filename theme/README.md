# Goalify Mobile — Next.js

Recreación funcional de las dos capturas: splash/intro y dashboard móvil de fútbol con glassmorphism.

## Ejecutar

```bash
npm install
npm run dev
```

Abre `http://localhost:3000`.

## Incluye
- Splash con transición automática y tap para saltar.
- Header de usuario + notificaciones.
- Búsqueda funcional de partidos.
- Chips de competición seleccionables.
- Live match Brasil vs Marruecos.
- Tabs Latest / Following / Top News.
- Próximos partidos con botón Watch.
- Barra de navegación inferior funcional.
- Diseño responsive para móvil y preview tipo teléfono en desktop.
- Glassmorphism con blur, transparencias, bordes suaves y fondos degradados.

Los escudos/banderas están representados sin dependencias externas para que el proyecto funcione inmediatamente.
